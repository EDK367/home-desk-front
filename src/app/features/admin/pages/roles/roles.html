Reglas de Seguridad y Autorización del Backend

Los roles del sistema son administrados a nivel de backend y controlan el acceso por método mediante directivas de seguridad. El rol de Administrador puede crear y editar usuarios asignándoles los roles operativos (Compras, Inventario, Ventas), mientras que la asignación del rol de Administración está reservada a nivel de base de datos.
